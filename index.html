Version 1.1.1.4 • Release Notes
  • Bruce SD Card Bootloop & Display Fix: Resolved the SD-card bootloop with half-red flicker and low-brightness purple screen by removing the ST7789 debug red GRAM fill, resolving the GPIO 40 LCD reset vs. speaker WCLK pin conflict, stabilizing the shared TFT/SD/CC1101 SPI bus at 40 MHz with an 80-clock SD wake sequence, closing leaked config/theme file handles, and adding automatic RTC Safe Boot recovery if SD configs corrupt.
  • Aligned SD Card Defaults: Updated generated bruce.conf defaults (colorInverted: 1, rfModule: 1, clean theme/startup keys) to match LilyGO T-Embed CC1101 Plus hardware.
  • Included from v1.1.1.3: Full Zhilly AI connected Arabic & Turkish fonts, flicker-free Options menu, autonomous eye blinking, zero echo loop, and clean Flipper Zero Main Menu switching.
